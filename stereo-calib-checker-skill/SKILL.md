# stereo-calib-checker：双目标定质检

给一组双目棋盘格标定图像做"体检"，回答三个问题：

1. **这组数据能不能标？**（张正友原文判据：≥3 张理论下限、避免纯平移/正对退化、角点覆盖充分）
2. **标出来的参数可信吗？**（重投影误差、内参合理性、基线与双目刚性）
3. **立体校正到底齐没齐？**（校正后左右同名点的垂直视差 dy，棋盘角点 + SIFT 特征点双路验证）

## 何时使用

- 用户提供了双目标定图像（棋盘格），想知道质量好坏、能不能用
- 标定完成后想验证极线校正效果
- 新手标定结果异常（测距漂移、视差图错乱），需要定位是数据问题还是参数问题

## 输入要求

- 一个目录，内含左右图像对，文件名分别含 `left` / `right` 记号（如 `left01.jpg` 与 `right01.jpg`，配对键为去掉记号后的余部）
- 棋盘格规格：内角点数（= 格子数 − 1），默认 9×6
- 图像建议 ≥10 对、姿态多样（不同倾角与面内旋转）

## 用法

```bash
pip install -r requirements.txt
python scripts/run_check.py --input <图像目录> --board-w 9 --board-h 6 --out <输出目录>
```

常用参数：
- `--square 25`：方格边长（mm 等），决定基线读数单位
- `--expected-baseline 120`：预期基线（与 --square 同单位），核验外参
- `--only-ids 01,02,03` / `--exclude-ids 05,07`：子集实验（复现退化/剔除坏图）
- `--max-vis 6`：保存前 N 对红蓝立体图与极线叠加图

无网络依赖，纯本地计算，图像只读不修改。

## 输出解读

`report.json`（结构化，供 Agent 转述）与 `report.md`（表格，供人阅读），每个检查项含
`status / value / criteria / advice`：

| 状态 | 含义 | 处置 |
|---|---|---|
| PASS | 达标 | — |
| WARN | 可用但有风险 | 按建议改进，或接受并记录 |
| FAIL | 不可用 | 按建议重采/重标 |
| INFO | 参考信息 | 酌情处理 |

关键阈值（经验值）：
- 有效图像对：≥10 PASS，3~9 WARN，<3 FAIL
- 板面最大倾斜角：<10° FAIL（张正友退化配置），10~15° WARN
- 板面朝向最大夹角：<10° FAIL，10~20° WARN
- 重投影误差：<0.5px PASS，0.5~1px WARN，>1px FAIL
- 极线垂直视差 |dy|：均值 <0.5px PASS，0.5~1px WARN，>1px FAIL

## 常见问题 → 修复建议

- **姿态退化 FAIL**：补拍多方向倾斜 15°~45° 的照片，避免只平移相机
- **数量 WARN**：积累到 10~20 对再标
- **覆盖 WARN**：让棋盘出现在画面四角与边缘（畸变估计靠边缘观测）
- **逐图误差离群**：用 `--exclude-ids` 剔除坏图重跑，对比极线误差变化
- **极线 WARN/FAIL**：剔除离群图重标；仍差则检查棋盘平整度与角点规格

## 局限性

- 仅支持平面棋盘格（rectangle / checkerboard），暂不支持 ChArUco 与圆形网格
- 阈值为经验值，未按相机分辨率自适应
- 双目刚性检查假设并排同向安装的常规双目架
- 结果为辅助预检，不替代正式验证流程；关键应用请人工复核
